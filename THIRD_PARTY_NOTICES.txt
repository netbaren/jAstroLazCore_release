jAstroLazCore - mentions tierces et crédits
================================================

Version : 2.4
(English version: THIRD_PARTY_NOTICES_EN.txt)

Ce projet est une application d'astronomie Lazarus / Free Pascal. Les paquets
publics générés par les scripts `uPS` contiennent les exécutables Windows et les
ressources runtime, pas l'arbre source privé du projet.

Inspirations historiques
------------------------

- Applets astronomiques de Juergen Giesen : étude et inspiration historiques.
  Aucun code d'applet n'est redistribué dans le paquet runtime public.

- JPARSEC, T. Alonso Albi, Espagne : package Java dédié à l'astronomie et à la
  dynamique céleste, utilisé comme référence historique et conceptuelle du
  travail Java initial. Aucun binaire ou source JPARSEC n'est redistribué dans
  le paquet runtime public. Mention communiquée à l'auteur, qui l'a accueillie
  favorablement (courriel du 28/10/2026).
  Code source JPARSEC : https://bitbucket.org/talonsoalbi/jparsec

- JavAstro, Filippo Bisognano, Italie : application d'astronomie Java, source
  d'inspiration historique après JPARSEC. Aucun binaire ou source JavAstro
  n'est redistribué dans le paquet runtime public.

Ressources complémentaires
--------------------------

- Shadows Pro, conception de cadrans solaires et d'astrolabes,

  Shadows n'est repris dans jAstroLaz. Mention et formulation validées par

Catalogues, modèles et données astronomiques
--------------------------------------------

- Bright Star Catalog / Yale Bright Star Catalog (D. Hoffleit, W. H. Warren Jr.) :
  utilisé via `resources/starsCatalog` pour le rendu des étoiles brillantes.

- VSOP / VSOP87 : théorie planétaire et données associées, produites à
  l'origine par l'IMCCE / Bureau des longitudes. Depuis la fusion de l'IMCCE
  avec le SyRTE au sein du Laboratoire Temps-Espace (LTE, 1er janvier 2025),
  ces données sont diffusées par le Service Espace de l'Observatoire de Paris
  (SE-OP) sous Licence Ouverte 2.0
  (https://github.com/etalab/licence-ouverte/blob/master/LO.md), confirmé par
  courriel par M. Mickaël Gastineau (LTE) le 27/10/2026.
  Source : Service espace de l'Observatoire de Paris - données mises à jour
  le 24/09/2026.
  (voir CGU, https://seop.obspm.fr/cgu/, section "Conditions applicables aux
  données").

- INPOP19a : éphémérides planétaires et lunaires, mêmes conditions que VSOP87
  ci-dessus (Licence Ouverte 2.0, SE-OP, confirmé le 27/10/2026).
  Source : Service espace de l'Observatoire de Paris - données mises à jour
  le 24/09/2026.
  Les caches runtime locaux sont reconstruits depuis les fichiers ASCII
  INPOP19a ; seuls ces caches dérivés sont redistribués avec le paquet public,
  pas les sources ASCII originales.

- IANA Time Zone Database : utilisée pour générer `resources/timezones.csv`.
  La version TZDB utilisée figure dans l'en-tête de ce fichier.

- PascalTZ : générateur de fuseaux horaires basé sur les sources PascalTZ
  présentes sous `tools/PascalTZ`, initialement par José Mejuto et maintenues
  par Denis Kozlov. Les fichiers locaux indiquent une licence LGPL / modified
  LGPL.

- Voie lactée (contours et zones, fichiers MWSMP6) : données de José R. Vieira
  (São Paulo, Brésil, 2000), diffusées avec SkyChart / Cartes du Ciel.
  Elles s'appuient sur l'ouvrage "Uranografia, Descrição do Céu" de
  R. R. de Freitas Mourão et sur une photomosaïque de la Voie lactée
  d'Axel Mellinger. Texte d'origine de l'auteur, reproduit tel quel :

    The outline 1 and shade 1 are based on the book 'Uranografia, Descrição
    do Céu', by R.R. de Freitas Mourão, a Brazilian astronomer. The equatorial
    coordinates were manually taken from his maps. Then, they were converted
    to galactic coordinates using Microsoft Excel and manually inserted onto a
    bitmap as black pixels over a white background. The bitmap dimensions were
    450 by 3600 pixels, making each pixel correspond to 0.1 degree. The pixels
    were manually connected (and their connections smoothed) using Adobe
    Photoshop 3.0. That created the base for outline 1. Finally, the space
    between the two curves defining outline 1 was filled with black pixels,
    creating the base for shade 1.

    The outlines and shades 2 to 5 are based on a photomosaic of the Milky Way
    created by the German astrophotographer Axel Mellinger. The original
    picture, dowloaded from his website
    (http://canopus.physik.uni-potsdam.de/~axm/astrophot.html), was 300 by
    2400 pixels in size. It was expanded to 450 by 3600, using Adobe
    Photoshop. Still in Adobe Photoshop, an 1 pixel 'minimum' filter was
    applied to eliminate individual star images. After some adjustmests in
    brightness and contrast and conversion to a grayscale bitmap, a 2 pixels
    'gaussian blur' filter was used to create a 'cloudy' aspect. Then, a
    'trace contour' filter was applied in four brightness levels, creating the
    bases for outlines 2 to 5. These were filled with black pixels, creating
    the bases for shades 2 to 5.

    Once the base bitmap files had been created, an application written in
    Microsoft Visual Basic 6.0 was used to scan the images, find black pixels,
    get their coordinates in pixels, convert them to galactic coordinates and
    then to equatorial coordinates which were sent to text files. These are
    the DAT files included in MWSMP6.ZIP.

    The average distance between each point in the outlines is 0.1° or 6'.
    For the shades, it is 0.4º or 24'.

    José R. Vieira, Sao Paulo, Brazil, Feb/2000
